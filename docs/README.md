# Dokumentasi Absensi Monitor

Aplikasi internal untuk memeriksa kehadiran dan integritas laporan Excel. Angka di dasbor dan laporan dihitung ulang dari baris harian, bukan dari baris Total pada berkas.

| Dokumen | Untuk siapa |
| --- | --- |
| [Panduan pengguna](PANDUAN-PENGGUNA.md) | Pegawai, manajer, peninjau, dan siapa pun yang memakai dasbor, koreksi, pengajuan, atau laporan |
| [Panduan admin](PANDUAN-ADMIN.md) | HR Admin dan Super Admin: data master, unggah, pemantauan, akun |
| [Skema basis data](SKEMA-DATABASE.md) | Yang perlu memahami tabel, relasi, dan data yang tidak boleh diubah |
| [Jenis anomali](ANOMALI.md) | Arti tiap temuan dan siapa yang menutupnya |
| [Matriks RBAC dan CRUD](RBAC.md) | Izin per peran dan batas tiap aksi |
| [README](../README.md) | Menjalankan aplikasi, cadangan, dan runbook operator |

Nama menu di aplikasi memakai Bahasa Indonesia. Nama kolom di basis data memakai bahasa Inggris.
